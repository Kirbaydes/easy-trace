# Easy Trace

Плагин для Figma: выделяешь слой с картинкой — получаешь редактируемый чёрно-белый векторный
силуэт рядом с оригиналом.

## Установка

```bash
npm install
npm run build
```

Дальше в десктопном приложении Figma: **Plugins → Development → Import plugin from manifest…** и выбрать
`manifest.json` из этой папки.

Во время разработки удобнее `npm run watch` — после пересборки плагин нужно перезапустить в Figma.

## Как работает

1. Выдели слой, залитый картинкой (фрейм, прямоугольник, любая фигура с image fill).
2. Плагин сразу берёт исходные пиксели, обводит силуэт и показывает превью с числом путей.
3. Крутишь настройки — превью пересчитывается само, холст при этом не засоряется.
4. **Add vectors** кладёт результат справа от оригинала, тем же размером и в том же родителе.
   Исходник остаётся нетронутым.

Результат вставляется через `figma.createNodeFromSvg`, то есть это обычные векторные слои Figma
с заливками — их можно править узлами, перекрашивать и собирать в компоненты.

## Настройки

Их три, и все три видны сразу.

**Threshold** — порог яркости. Всё темнее него уходит в силуэт, всё светлее становится фоном.
Прозрачные пиксели считаются фоном всегда.

**Invert** — меняет фигуру и фон местами. Нужен для светлого рисунка на тёмном: без инверсии
плагин обведёт подложку, а не сам знак.

**Transparent background** — включён по умолчанию: результат ложится на прозрачность. Если
выключить, под силуэт подкладывается белый прямоугольник.

### Чем трассирует

Основной движок — **potrace**, собранный в WebAssembly (`esm-potrace-wasm`), с его собственными
выверенными умолчаниями (`turdsize 4`, `alphamax 1`, `opttolerance 0.2`). Он подгоняет кубические
кривые Безье с определением углов, поэтому окружности выходят круглыми, а не многоугольными.
Wasm вшит прямо в JS-файл пакета: ни сети, ни отдельных файлов не требуется.

Если WebAssembly в песочнице почему-то недоступен, плагин молча откатывается на чистый JS
(`imagetracerjs`) и пишет об этом в «Диагностику». Контуры там заметно грубее — этот путь только
страховочный.

Перед трассировкой картинка ужимается до 1024 px по длинной стороне: для силуэта этого достаточно,
а считается заметно быстрее.

## Устройство

```
manifest.json      манифест плагина
build.mjs          esbuild: собирает code.js и инлайнит UI в один ui.html
src/code.ts        main-поток: поиск заливки-картинки, выдача пикселей, вставка результата
src/ui.ts          интерфейс, трассировка (potrace-wasm + запасной imagetracerjs), превью
src/ui.html        разметка и стили
src/types.ts       общие типы сообщений между потоками
```

Трассировка — [potrace](https://potrace.sourceforge.net/) через
[esm-potrace-wasm](https://www.npmjs.com/package/esm-potrace-wasm), запасной движок —
[imagetracerjs](https://github.com/jankovicsandras/imagetracerjs). Всё считается прямо в iframe
плагина. Настройки и язык запоминаются в `figma.clientStorage`. Сеть не используется.

Сборка подменяет `node:*`-импорты пустыми модулями: внутри `esm-potrace-wasm` есть ветка для Node,
которая в браузере не исполняется, но сборщику её надо чем-то закрыть.

Интерфейс на английском и русском, переключатель в шапке.
